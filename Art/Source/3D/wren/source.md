# Рен (wren) — базовая 3D-модель (A-Roster3D, 2026-10-20)

Скрипт: `blender -b --factory-startup --python Tools/Blender/fighters/build_wren.py -- [out_dir]` (Blender 5.2.2, ≈ 90 с).
Лист: `blender ... --python Tools/Blender/fighters/render_wren_sheet.py` → `Tools/out/art/roster3d/wren_sheet.png`
(спереди | 3/4 | сзади | сбоку | сверху | игровая 55° | крупно | оружие).

| Файл | Треуг. | Что внутри |

## Формат
Как у Тео: Z вверх, лицом к −Y, ноги z = 0, центр X/Y; FBX `axis_forward=-Z, axis_up=Y`, `colors_type=SRGB`.
**Рост 0.78** (Тео = 1.0; ей 8 лет). Метод — SDF из примитивов → surface nets → две оболочки (голова 1 891, тело 1 990)
с децимацией → smart UV → покраска каждого текселя на точной поверхности (глаза, веснушки, щербинка, блёстки, звёзды).

## Кости (координаты экспорта, Blender)
Root (0,0,0) · Body (0,0,.267) · Head (0,0,.452)→(0,0,.763) · ArmR/ArmL плечо (∓.090,.004,.428) → запястье ·
LegR/LegL бедро (∓.049,.004,.267) → лодыжка · **Prop** = центр правой кисти (−.039,−.185,.327), хвост вдоль −Y ·
EyeR/EyeL/LidR/LidL (∓.061,−.12,.572), хвост по взгляду (−Y). Веса: жёстко по деталям, плавно плечо (Arm↔Body),
бедро (Leg↔Root), талия (Body↔Root); ≤ 2 влияний. Tail/Extra нет.
Хват двумя руками: правая кисть впереди, левая сзади на той же рукояти (рукоять вдоль −Y, перед животом над пачкой).

## Оружие «Скрип» (меч-дверь)
Начало координат = центр рукояти под правой кистью (вешать на Prop без смещения). Клинок вдоль −Y, наклон 11° кончиком
вниз (конец почти у земли — «тянется по земле»), поворот плоскости 12°. Длина 1.125 (больше её роста), ширина 0.27,
толщина 0.037. Детали: светлое дерево `#D9B48A` с двумя утопленными филёнками с обеих сторон, текстура волокон,
латунная щель для писем, две петли (серый металл), латунная розетка-гарда + дверная ручка-шар сбоку (латунь `#E8C15A`),
деревянная рукоять с персиковой обмоткой, латунное навершие. Пустышки `Muzzle` нет (ближний бой).
Для ульты (свечение ручки) — в Unity по материалу/эмиссии латуни; отдельной геометрии нет.

## Палитра (sRGB)
Roster-v4: персик `#FFB48A` (пачка, воротник), ленты `#FF9E70`, слоновая кость `#FFF6E6` (футболка), дерево `#D9B48A`,
латунь `#E8C15A`. Свои (решение агента, в Roster-v4 не заданы): кожа `#FCD6BC`, рыжие волосы `#C2602E` (к веснушкам),
шлем `#7FD8C4` и сапожки `#5FC3AE` — мятные (синий/красный заняты командами), леггинсы `#7C5A62`, глаза — карие.
Глянец (alpha): кожа 0.18, волосы 0.35, ткань 0.12–0.18, шлем 0.75, сапоги 0.85, латунь 0.9, дерево 0.2–0.25.

## Похоже / не сделано
Есть: крупная голова, два пучка с бантами, велошлем с вентиляцией и звёздами-наклейками, веснушки, щербинка,
пышная пачка-круг, сапожки с блёстками, огромная дверь — сверху читается «точка + доска».
Нет: глаза нарисованы на текстуре (нет геометрии глаз на EyeL/R — веки/взгляд процедурно в Unity), витринной (show)
версии нет, гребень шлема грубоват, кисти — «варежки», нет щели для писем насквозь (только краска).
