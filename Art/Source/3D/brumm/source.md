# Брумм (`brumm`) — 3D-основа (A-Roster3D, 2026-10-20)

Образ — `Docs/Roster-v4.md` §6.4: здоровяк ≈16 в броне-«бочке» из цистерны, шлем-иллюминатор, горшок с кактусом Колюшем
на левом плече, «Шишкомёт» в обеих руках. Метод и формат — как Тео v3 (`build_theo_v3.py`; библиотека SDF, сетка, UV,

## Формат
Blender: Z вверх, лицом к −Y, рост 1.0 (ширина 0.67 — «шайба»; масштаб крупнее Тео задать в рецепте), FBX `axis_forward=-Z, axis_up=Y`.
Кости (после нормировки ×1.042, сдвиг y +0.0045): Root (0,0,0)→Body (z .26)→Head (z .69…1.0); ArmR/L плечо (∓.242,.005,.59) →
запястье (∓.156,−.204,.43); LegR/L бедро (∓.104,.005,.26) → лодыжка (∓.106,0,.07); **Prop** = центр правой кисти
≈ (−.123, −.231, .425) (точно — из головки кости); EyeR/L, LidR/L — центры нарисованных глаз (≈ ±.041, −.09…, .84), веки без геометрии.
Веса жёсткие (1 влияние) по деталям: ноги/сапоги → Leg, руки/перчатки → Arm, шлем/лицо/обод → Head, бочка/горшок/кактус → Body.
Оружие: начало = хват правой руки (вешать на Prop без смещения), ствол −Y, корпус по центру между руками (левая рукоять x ≈ +.246),
`Muzzle` ≈ (.123, −.365, .031) в локальных осях оружия.

## Палитра
песок `#E3D3A8` (бочка, шлем, руки), бирюза `#3FB59B` (кактус, обод иллюминатора, манометр, вентиль), шоколад `#5A3E2B`
(обручи с заклёпками, воротник, перчатки, сапоги, стволы), тёплый свет `#FFF4D6` (только цветок Колюша), глина горшка `#94603C`.

## Не успел / упрощения
- Веса жёсткие, без плавных стыков в плече/бедре (у Тео — мягкие); талии нет (бочка целиком на Body).
- Стекла иллюминатора нет (лицо открыто в ободе); пар у оружия, шишки-снаряды — не сделаны.
- Небольшие тёмные пятна запекания под обручами сбоку (проекция на скруглении бочки); vertex colour оружия плоский, без AO.
- В Unity не проверялся (запрет брифа).
