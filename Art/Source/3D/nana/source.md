# Бабуля Чилл (Nana Chill) — базовая 3D-модель (A-Roster3D, волна 2, 2026-10-20)

Образ — `Docs/Roster-v2.md` №13 (в v3/v4 без изменений): бабушка ≈70, лекарь-аура, восточноазиатские черты, седые волосы;
сверху — коврик-рулон за спиной и пучок со спицами; термос. Самая невозмутимая: глаза полуприкрыты, круглые очки, спокойная улыбка.

Сборка: `blender -b --factory-startup --python Tools/Blender/fighters/build_nana.py -- [out_dir]` (≈ 15 с).
Лист: `Tools/Blender/fighters/render_nana_sheet.py` → `Tools/out/art/roster3d/nana_sheet.png` (спереди | 3/4 | сзади | сверху | игровая 55° | оружие).

## Метод
Как `build_lark.py`: аналитические примитивы → voxel remesh 4.5 мм → цвет граней по приоритетам (декали без геометрии:
оправа очков, глаза с полуопущенным веком, брови, румянец, рот, пуговицы, открытый ворот, ремень коврика) → decimate →
smart UV → запекание hi→low. Z вверх, лицом к −Y, рост ≈ 0.98 с пучком (голова ниже, чем у Тео: бабушка невысокая),
FBX `axis_forward=-Z, axis_up=Y`, `colors_type=SRGB`.

## Кости (Blender)
Root (0,0,0)→(0,0,.38) · Body →(0,0,.64) · Head (0,0,.64)→(0,0,1.0) · ArmR плечо (−.15,0,.55)→кисть (−.12,−.14,.40) ·
ArmL (.15,0,.55)→(.15,−.10,.36) · LegR/L бедро (∓.065,0,.32)→лодыжка (∓.075,0,.085) · **Prop** (родитель Body) = правая кисть
(−.12,−.14,.40), хвост по −Y · EyeR/L (∓.062,−.142,.725), LidR/L там же, без геометрии. Пучок, спицы — на Head; коврик — на Body;
подол кардигана ниже z .40 — на Root. Веса жёсткие. `Extra` не нужен.

## Оружие (термос)
Начало = ручка под правой кистью (вешать на Prop без смещения), термос вдоль −Y (длина ≈ 0.2), верх +Z: бирюзовая колба
с тёмными поясками, стальное горлышко, белая крышка-чашка, тёплое свечение чая. `Muzzle` = (0, −0.19, 0.06) — пар/брызги чая.

## Палитра (sRGB)
Кожа `#EBC39C`, румянец `#E79A8A`, волосы `#DADBE2` (тень `#B9BAC6`), кардиган мятный `#7FCBB4` (кайма `#5FAE97`), рубашка
`#FFF3DC`, пуговицы `#F2B33D`, легинсы сливовые `#5B4A7A`, кеды `#F7F5F0`, коврик коралловый `#F2896B` (торцы `#F9B9A2`,
ремни `#6B5390`), спицы `#E8B84A` с коралловыми бусинами, оправа `#8E3B5A`, термос `#3FA7C9`/`#2C7E9C`, чай-свечение `#FFE3A6`.

## Не успела / упрощено
Веса без плавных стыков; кисти — шары без пальцев; спиралей на торцах коврика нет (просто светлее); глаза полуприкрыты
статично в текстуре (моргание — LidR/L в аниматоре можно не использовать); без Flow-референса.
