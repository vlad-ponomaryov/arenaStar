# Ларк — базовая 3D-модель (A-Roster3D, 2026-10-20)

Образ — `Docs/Roster-v2.md` §4 №5 (в Roster-v4 без изменений): разведчица 14 лет, медное каре, веснушки, очки-«лётчики» на лбу,
горчичная куртка-бомбер с меховым воротником, дрон Пикс «крестиком» над правым плечом, длинный пусковой «гарпунчик» с дротиком-присоской.

Сборка: `blender -b --factory-startup --python Tools/Blender/fighters/build_lark.py -- [out_dir]` (≈ 7 с).
Лист: `.../render_lark_sheet.py` → `Tools/out/art/roster3d/lark_sheet.png` (спереди | 3/4 | сзади | сверху | игровая 55° | оружие).

## Метод
Примитивы (эллипсоиды/капсулы, аналитические) → voxel remesh 4.5 мм (цельная гладкая оболочка) → цвет граней по списку
примитивов с приоритетами (декали без геометрии: радужка, зрачок, блик, рот, веснушки, молния, шеврон) → decimate → smart UV →
запекание hi→low. Формат как у Тео: Z вверх, лицом к −Y, рост 1.0 (верх волос ≈ 0.99), FBX `axis_forward=-Z, axis_up=Y`,
`colors_type=SRGB`, `Col` — плоский цвет по граням (запасной для шейдера по вершинам), alpha = глянец.

## Кости (Blender)
Root (0,0,0)→(0,0,.40) · Body →(0,0,.64) · Head (0,0,.64)→(0,0,1) · ArmR плечо (−.15,0,.60)→кисть (−.12,−.10,.42) ·
ArmL (.15,0,.60)→(−.09,−.27,.44) (левая рука держит ствол) · LegR/L бедро (∓.06,0,.36)→лодыжка (∓.075,0,.09) ·
**Prop** (родитель Body) = правая кисть (−.12,−.10,.42), хвост по −Y · EyeR/L (∓.062,−.142,.775), LidR/L там же, без геометрии ·
**Extra** (родитель Body) = дрон (−.25,.07,.96) — для покачивания/вращения в аниматоре. Веса жёсткие (1 кость на вершину).
Глаза нарисованы в текстуре (на кости Head).

## Оружие
Начало = рукоять под правой кистью (вешать на Prop без смещения), ствол вдоль −Y, верх +Z. Длина ≈ 0.6 роста: белая труба
с бирюзовыми кольцами, горчичный приклад, графитовый прицел со светящейся линзой, оранжевое дуло, дротик с коралловой
присоской. `Muzzle` — (0, −0.42, 0.055) в локальных координатах оружия.

## Палитра (sRGB)
Кожа `#F4CDB0`, медь волос `#B85A2A`, куртка `#D6A12B` (кайма `#B5841C`), мех `#EFE1C2`, штаны `#4B5245`, ботинки `#6A4428`,
перчатки `#4A3326`, очки: латунь `#C9A04A` + линзы `#5FC6CF`, радужка зелёная `#3E7A4E`, веснушки `#C98A62`,
дрон `#E9ECEF`/`#4A4F57`, свечение `#48D6E0`, присоска `#FF6B4A`, дуло `#F07A2A`.

## Не успела / упрощено
Веса без плавных стыков (плечо/бедро); кисти — шары без пальцев; нет швов/карманов бомбера, нет ремешков ботинок; веснушки
и рот — простые пятна; голова/лицо не сверены с Flow-референсом (его для Ларк нет); оружие без текстуры (цвет вершин).
