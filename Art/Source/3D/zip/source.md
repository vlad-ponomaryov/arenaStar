# Зип (zip) — 3D-основа (A-Roster3D, 2026-10-20)

Образ — `Docs/Roster-v2.md` §4 №6 (15 лет, паркурщик с тросом-кошкой, ассасин): оливковая кожа, тёмные взъерошенные
волосы, чёрная толстовка с малиновыми вставками, **длинный малиновый шарф-шлейф** и **жёлтый моток троса на спине**
(читаются сверху), без ниндзя-символики.

Сборка: `blender -b --factory-startup --python Tools/Blender/fighters/build_zip.py -- [out_dir]` (≈ 55 с, Blender 5.2.2, numpy).
Лист: `.../render_zip_sheet.py` → `Tools/out/art/roster3d/zip_sheet.png` (спереди | 3/4 | сзади | сбоку | сверху | игровая 55° | оружие).
Метод — упрощённый Тео v3: SDF-примитивы (классы из `build_theo_v3.py`) → surface nets → децимация → smart UV →
каждый тексель возвращается на точную поверхность и красится процедурно (глаза, брови, ухмылка, румянец, полосы рукавов,
молния, витки троса, AO из поля, мягкий свет сверху).

## Формат — как Тео v3
Blender Z вверх, лицом к −Y, рост 1.0, ноги на z = 0, X/Y по центру тела (шарф торчит назад до y ≈ +0.42).
FBX `axis_forward=-Z, axis_up=Y, colors_type=SRGB, add_leaf_bones=False`. Макс. 2 влияния на вершину (мягкие стыки 8 мм).

## Кости (нормированные координаты Blender)
Root (0,0,0)→Body (0,0,.42)→(0,0,.67) · Head (.67→1.0) · ArmR плечо (−.126,.006,.616)→запястье (−.156,−.133,.474) — правая
рука вытянута вперёд с оружием · ArmL (.126,.006,.616)→(.190,−.049,.437) — свободная, чуть вперёд · LegR/LegL бедро (∓.055,.005,.42)
→лодыжка (∓.069,.006,.096) · **Prop** (родитель Body) — центр правой кисти **(−.152, −.165, .461)**, хвост вдоль −Y ·
EyeR/EyeL — у поверхности глаз (≈ (∓.043, −.091, .792)), хвост по взгляду (−Y) · LidR/LidL — там же, без геометрии.
Шарф и трос — на Body (отдельной кости Tail/Extra нет; анимация шарфа — позже).

## Оружие «Кошкомёт» / Hookshot
Начало координат = центр рукояти (вешать на Prop без смещения), ствол вдоль −Y (в Unity +Z), верх +Z. Длина ≈ 0.26 роста:
графитовая рукоять со скобой, малиновый корпус, жёлтая катушка троса сбоку (металлические колпачки), металлическая муфта,
жёлтый трос и трёхлапая кошка. `Muzzle` = (0, −0.212, 0.049) — точка вылета троса.

## Не успел / упрощено
- Шарф — жёсткий шлейф из одного меша (без кости), чуть «зубчатый» сверху; капюшон за шеей простой.
- Кисти — «варежки» без пальцев; пятерня не обхватывает рукоять. Лицо — нарисованное (брови тонкие).
- Перчатки для атаки-«хлопка» без отдельной детализации; игровая проверка в Unity — не делалась (Unity не запускали).
