# Ковач — базовая 3D-модель (A-Roster3D, 2026-10-20)

Сборка: `blender -b --factory-startup --python Tools/Blender/fighters/build_kovach.py -- [out_dir]` (≈ 2 мин, Blender 5.2.2, numpy).
Лист: `.../render_kovach_sheet.py` → `Tools/out/art/roster3d/kovach_sheet.png` (спереди | 3/4 | сзади | сверху | игровой 55° | молот).
Метод — как Тео v3 (библиотека SDF скопирована из `build_theo_v3.py`), но проще: одна оболочка → surface nets 3 мм →
квадрик-децимация → smart UV 66° → запекание 1024 (цвет детали × свет/AO по полю + блик; A = глянец) → `Col` = текстура (размытая).

| Файл | Треуг. | Что |
| --- | --- | --- |
| `kovach_game.fbx/.glb` | 3 930 (≤ 4 000) | меш `Kovach`, UV `UVMap`, `Col`, арматура `Rig` 12 костей, материал `FighterVC` → `kovach_tex.png` |
| `kovach_weapon.fbx/.glb` | 1 174 (≤ 1 200) | меш `KovachHammer` (кузнечный молот), без костей, материал → `kovach_weapon_tex.png` |

Формат как у Тео: Z вверх, лицом к −Y, высота 1.0 (ноги z = 0); FBX `axis_forward=-Z, axis_up=Y`, `colors_type=SRGB`.
**Масштаб в игре** — танк крупнее: в рецепте ≈ 1.2–1.3 от Тео (рост «в полтора Тео», GDD: танк сверху ≈ 1.2).

## Кости (головки, Blender после нормировки)
Root (0,0,0) · Body (0,0,.416) · Head (0,0,.732) · ArmR/L плечо (∓.248,0,.653) → запястье (∓.311,−.079,.374) ·
LegR/L бедро (∓.09,0,.374) → лодыжка (∓.105,0,.090) · **Prop** = центр правой кисти (−.311,−.100,.326) ·
EyeR/L = LidR/L (∓.049,−.110,.856), глаза — геометрия + текстура, без весов (веки процедурные).
Веса жёсткие по деталям; талия Root↔Body плавно (z .38–.46 до нормировки); ≤ 2 влияний.

## Молот
Начало = центр рукояти под хват правой кистью (вешать на Prop без смещения), рукоять вдоль −Y («вперёд» = взгляд),
боёк поперёк (по Z), брусок 0.18 × 0.16 × 0.30 — крупнее головы героя; янтарная светящаяся полоса по бойку
(для «раскалённого» молота в ульте — подкрасить/эмиссия в Unity). Длина 0.63, Muzzle не нужен (ближний бой).

## Палитра (sRGB → глянец)
кованое железо `#5B5F66` 0.8 (молот, наручи), тёмное железо `#3E4148` (сапоги, оправа очков) · жжёная охра `#C77A2E` 0.3
(фартук), тёмная охра `#8E5420` (ремни, пояс, карман) · лён `#EFE3C8` 0.12 (рубаха с закатанными рукавами) ·
горн `#FFB347` 1.0 (линзы очков, полоса молота) · кожа `#7A4A2E`, борода/брови `#1E1A18`, штаны `#4A3A2E`, рукоять `#8A5A32`.

## Что есть / чего нет
Есть: великан с широкими плечами и трапецией фартука, бритая голова, короткая чёрная борода, янтарные очки на лбу,
наручи, огромные кисти, сапоги, молот в правой руке; силуэт сверху — «плечи + фартук + брусок молота + огоньки очков».
Нет (не успел): улыбка читается как приоткрытый рот, нет морщинок у глаз; кисти — «варежки» без пальцев; молот в руке,
а не на плече (поза «на плече» — забота аниматора/позы ожидания); нет кармана-банки с бабочкой; витринной (show) версии нет;
проверки силуэта по референсу нет (Flow-референса Ковача пока нет).
