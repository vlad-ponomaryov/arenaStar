# Дозер — базовая 3D-модель (A-Roster3D волна 2, 2026-10-20)

Сборка: `blender -b --factory-startup --python Tools/Blender/fighters/build_dozer.py -- [out_dir]` (≈ 3 мин, Blender 5.2.2, numpy).
Лист: `.../render_dozer_sheet.py` → `Tools/out/art/roster3d/dozer_sheet.png` (спереди | 3/4 | сзади | сверху | игровой 55° | подушка).
Метод — как Ковач/Тео v3 (SDF → surface nets 3 мм → децимация → smart UV → запекание 1024, A = глянец; `Col` = текстура).
Узоры запекаются процедурно: клетка пижамных штанов, полосы наволочки, вязаные рубчики свитера.

| Файл | Треуг. | Что |
| --- | --- | --- |
| `dozer_game.fbx/.glb` | 3 930 (≤ 4 000) | меш `Dozer`, UV `UVMap`, `Col`, арматура `Rig` 13 костей, материал `FighterVC` → `dozer_tex.png` |
| `dozer_weapon.fbx/.glb` | 1 173 (≤ 1 200) | меш `DozerPillow` (подушка «Облако»), без костей, материал → `dozer_weapon_tex.png` |

Формат как у Тео: Z вверх, лицом к −Y, высота 1.0 с колпаком (ноги z = 0); FBX `axis_forward=-Z, axis_up=Y`, `colors_type=SRGB`.
**Масштаб в игре** — танк: ≈ 1.2–1.3 от Тео (колпак занимает верхние ~0.2 роста).

## Кости (головки, после нормировки)
Root (0,0,0) · Body (0,0,.279) · Head (0,0,.532) · ArmR/L плечо (∓.194,0,.473) → запястье (руки вытянуты вперёд к подушке) ·
LegR/L бедро (∓.081,0,.234) → лодыжка · **Prop** = центр правой кисти (−.271,−.230,.374) ·
**Extra** (0,.157,.91) — хвост колпака с помпоном (родитель Head; можно раскачивать при беге) ·
EyeR/L = LidR/L (∓.052,−.129,.692). Сонные веки — геометрия (верхняя половина глаза закрыта кожей).
Веса жёсткие по деталям; талия Root↔Body плавно (z .27–.35 до нормировки).

## Подушка
Начало = хват правой кисти (вешать на Prop без смещения); подушка 0.54 × 0.39 (после масштаба) лежит вправо по +X до левой
кисти, перед животом, верхний край наклонён вперёд на 28° — сверху самый крупный прямоугольник, шире плеч. Кремовая наволочка
с лаймовыми полосами, «ушки» по углам, золотая заплатка-звёздочка. Muzzle не нужен (ближний бой).

`#3E271C` (манжеты, ворот, низ свитера) · крем `#FFF1DC` (подушка, помпон), подошва `#EADCC4` · золото `#FFD45A` (ночник-полумесяц,
звёздочка) · кожа `#F4C6A6`, румянец `#F09A8C`, соломенные вихры `#E9C25E`, маска для сна `#3B3446`.

## Что есть / чего нет
Есть: крупный мальчик в мешковатом свитере, клетчатые пижамные штаны, тапки, большая голова, круглые щёки, сонные глаза,
щербинка (два зуба), маска для сна на лбу, вихры из-под колпака, длинный колпак с помпоном назад и ночником-полумесяцем.
Нет: перьев (это VFX), свечения ночника при готовой ульте (эмиссия/подкраска в Unity), отдельной кости хвоста-цепочки
(один Extra), кистей с пальцами (варежки), show-версии.
