# Ракс (Rax) — базовая 3D-модель (A-Roster3D, волна 2, 2026-10-20)

Образ — `Docs/Roster-v2.md` №14 (в v3/v4 без изменений): енот-плут, пакостник; атака — горсть жёлудей-«щелбанов», ульта
«Подмена» (узелок светится). Сверху — полосатый хвост и узелок. Формы — по Flow-концепту `Art/Source/Flow/2026-10-19_vex-raccoon`
(серый енот, тёмная маска, белые брови, кольца на хвосте); верёвку с кошкой из концепта заменили узелком по описанию.

Сборка: `blender -b --factory-startup --python Tools/Blender/fighters/build_rax.py -- [out_dir]` (≈ 15 с).
Лист: `Tools/Blender/fighters/render_rax_sheet.py` → `Tools/out/art/roster3d/rax_sheet.png` (спереди | 3/4 | сзади | сверху | игровая 55° | оружие).

## Метод
Как `build_lark.py`/`build_nana.py`: примитивы → voxel remesh 4.5 мм → цвет граней по приоритетам (декали: маска, белая
полоска на переносице, брови, глаза с хитрым прищуром, ухмылка с зубом, кольца хвоста, горошек узелка, лямка) → decimate →
smart UV → запекание. Z вверх, лицом к −Y, рост ≈ 0.98 по кончикам ушей; голова крупная, ноги короткие, корпус круглый.

## Кости (Blender)
Root (0,0,0)→(0,0,.35) · Body →(0,0,.63) · Head (0,0,.63)→(0,0,.99) · ArmR плечо (−.14,0,.54)→лапа (−.13,−.15,.42) ·
ArmL (.14,0,.54)→(.17,−.09,.38) · LegR/L бедро (∓.07,0,.29)→лодыжка (∓.085,0,.075) · **Prop** (родитель Body) = правая лапа
(−.13,−.15,.42), хвост по −Y · EyeR/L (∓.066,−.146,.755), LidR/L там же, без геометрии · **Tail** (родитель Root)
(0,.10,.27)→(0,.44,.47) — хвост целиком, для виляния · **Extra** (родитель Body) = узелок (0,.17,.56)→вверх — покачивание и
свечение на ульте. Веса жёсткие.

## Оружие
Жёлудь-«щелбан»: начало = хват в правой лапе (вешать на Prop без смещения), остриё вдоль −Y, шляпка с хвостиком назад.
`Muzzle` = (0, −0.10, 0.035). Бросок — тот же жёлудь как снаряд (можно взять этот меш).

## Палитра (sRGB)
Мех `#8E909C` (тёмный `#5E606B`), светлый мех `#E6E3EA`, живот `#C9C5D4`, маска/кольца/кончики ушей `#2E2F37`, лапы `#3A3A43`,
уши внутри `#C98FA0`, нос `#1E1E24`, радужка янтарная `#9A6A2C`, узелок `#D9503F` с горошком `#F6E7C8`, узел `#B83C2E`,
лямка `#7A4A2A`, жёлудь `#C27D3E` / шляпка `#6E4826`.

## Не успел / упрощено
Веса без плавных стыков; пальцев нет (лапы — шары); лямка видна только на животе; хвост одной костью (без изгиба по
сегментам); эффект «Притвориться» (фальшивый «пуф») и свечение узелка — дело VFX/аниматора.
