# Гала — базовая 3D-модель (A-Roster3D, 2026-10-20)

Образ — `Docs/Roster-v3.md` §3.1 (звезда шоу талантов, метатель), палитра — розовая жвачка `#FF8AD8` / золото `#FFC83D` /
белый / свечение софита `#FFF4B0`; кожа светло-оливковая `#E2BB92`, волосы чёрные глянцевые, легинсы сливовые `#6A3A6E`.
Конвейер — копия Тео v3: `Tools/Blender/fighters/build_gala.py` (общий код SDF / surface nets / децимация / UV / запекание /
риг скопирован из `build_theo_v3.py`, свои — модель, раскраска, оболочки, экспорт, оружие). Полная сборка ≈ 2,5 мин:
`blender -b --factory-startup --python Tools/Blender/fighters/build_gala.py -- [out_dir]`.
Лист: `render_gala_sheet.py` → `Tools/out/art/roster3d/gala_sheet.png` (спереди | 3/4 | сзади | сверху | игровой 55° | оружие).

Формат как у Тео v3: Z вверх, лицом к −Y, высота 1,0 (включая хвост и бант — тело ниже Тео ≈ на 7 %), ноги z = 0,
X по центру, **Y не центрируется по габариту** (ось тела = 0, хвост и бант уходят назад до y ≈ +0,23). FBX: `-Z` вперёд, `Y` вверх.

## Кости (головки после нормировки, Blender)
Root (0,0,−.006) · Body (0,0,.364) · Head (0,0,.623) · ArmR/L плечо (∓.100,.006,.575) → запястье · LegR/L бедро (∓.046,.005,.364) →
лодыжка · **Prop** = центр правой кисти (−.221,−.006,.362) · EyeR/L = LidR/L = центры нарисованных глаз (∓.043,−.092,.735).
Родители и веса — как у Тео v3 (жёстко по деталям, мягко плечо/бедро/талия; пышные плечи 0,6 Body + 0,4 Arm; жакет — по
костям тела как костюм). Хвост, бант, резинка — на Head (костей Tail/Extra нет).

## Оружие
Начало координат = центр рукояти (вешать на Prop без смещения), труба вдоль −Y (вперёд = взгляд), верх +Z. Розовая труба
r 0,042 (×0,93), золотые кольца, золотая заглушка сзади, мушка, курок, светящееся жерло `#FFF4B0`; `Muzzle` ≈ (0, −0,191, 0,052).

## Что есть / чего нет
Есть: огромный золотой бант-«бабочка» на высоком хвосте-фонтане (три пряди на конце), чёлка набок, большие глаза,
две наклейки-сердечка на левой щеке, улыбка; короткий розовый блестящий жакет-болеро с пышными плечами и золотым кантом,
белый топ, золотой пояс с мини-прожектором (светящаяся линза), розовая юбка, сливовые легинсы, белые ботильоны с розовой
манжетой и золотой подошвой, белые перчатки; розовый тубус-хлопушка на спине с золотыми кольцами и светящейся крышкой.
Нет / грубо (не успел, база): сверху хвост частично закрывает бант; на банте тёмные точки запекания; нет блёсток-шлейфа
(это эффект), нет диско-шара и коробки-сюрприза (реквизит способностей); перчатки — 3 пальца как у Тео; витринной LOD нет;
проверки силуэта по референсу нет (у Гала нет Flow-референса).
