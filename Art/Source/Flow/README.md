## Оценка

Лучше всего вышли **Пикс, Чомп, Векс и Нова**: ровно наш стиль (толстый тёплый контур, двухступенчатый cel, лавандовые тени),
силуэт сверху читается одной формой + одним акцентом, как в ТЗ §1.4. **Кора 002** хороша, но шея длинновата. **Бруно** — самый
слабый: пропорции «взрослого» мишки (голова ≈ 0,3 роста), не игрушка. Фон меню 001 — готов к использованию после виньетки.
Трава 002 спокойная (насыщенность низкая), без шахматки — подходит под правило «пол самый спокойный».

Оригинальность: звери, предметы и палитра — из нашего ТЗ; в промптах нет чужих игр, студий и художников. Похожих на
персонажей Supercell образов не вижу: жанровый «мультяшный зверь», без их пропорций, шрифтов, кнопок и значков.

## Что взять в рецепты моделей (A.1b–A.1d)

- **Общее.** Глаза — крупные, тёмно-карие с одним бликом, ставятся высоко (как у всех листов); белый «нагрудник» — отдельный
  светлый овал на животе (лиса, бобр, енот, медведь) — дешёвая деталь, хорошо читается спереди. Ступни — тёмные овальные «тапки».
- **Пикс.** Хвост ≈ высоте тела, с белым кончиком ≈ 1/3 длины, загнут в сторону и вверх; уши ≈ 0,45 высоты головы, тёмные
  кончики ≈ 1/3 уха; очки — два жёлтых кольца на тёмном ремешке, ремешок обходит голову (сзади это тёмная полоса — «лицо» спины).
  Бластер: бирюзовый корпус + светлый бак-цилиндр сверху, держится двумя лапами перед грудью.
- **Бруно.** Каска — полусфера с козырьком по кругу, ширина полей ≈ 1,3 ширины головы (между 001 и 002); уши торчат по бокам
  **под** полями; жилет — два горизонтальных светлых пояса + вертикальные на груди. Кулаки ≈ 0,5 ширины головы. Голову увеличить до 0,38.
- **Чомп.** Хвост-лопата ≈ 0,6 высоты тела, плоский овал, лежит на земле сзади (сверху — тёмный овал, главный признак);
  резцы — два кремовых прямоугольника; одна лямка через плечо, кирпичная сумка на бедре с 2–3 шишками; очки — два раздельных стекла.
- **Кора.** Панцирь-купол с кремовым ободом ≈ 0,08 радиуса, 6–8 крупных листьев светлее основы; спереди — кремовый пластрон;
  чайник лежит на куполе носиком вбок, цветок на боку чайника; лямки — коричневые. Шею укоротить (голова почти на панцире).
- **Нова.** Шар без шеи, ушки-пёрышки, «очки» из жёлтых колец вокруг глаз ≈ 0,35 ширины тела каждое; на груди 2–3 ряда
  серых «чешуек»; шарф — плотный валик на шее и **один длинный конец назад** (сверху он и есть силуэт); рогатка в крыле.
- **Векс.** Пригнутая поза, хвост ≈ высоте тела с 3–4 тёмными кольцами; маска — сплошная полоса через глаза с белыми бровями
  над ней; жёлтый моток-тор на спине + **один** крюк с одним загнутым зубцом (не якорь).
- **Цвета.** Сгенерированное близко к hex из ТЗ §1.3–1.4; брать значения из ТЗ, а не пипеткой с картинок (JPEG и cel-тени
  их сдвигают). Тень-пятно под бойцом на листах — лавандовая; у нас по ТЗ — тёмно-зелёная `#22301E`, не менять.
