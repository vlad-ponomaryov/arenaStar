## Как запустить

**Редактор:** Unity Hub → Add → `C:\Dev\Arena` (Unity 6000.3.26f1) → сцена `Assets/_Project/Scenes/Boot` → Play.
Клавиши (`KeyboardMouseInput`, через `LocalInputCollector`): WASD — движение; зажать ЛКМ — прицел, отпустить — выстрел;
Space — выстрел с автоприцелом; зажать ПКМ — прицел ульты, отпустить — ульта; E — ульта с автоприцелом; Q / левый Shift — трюк.

**Телефон:** включить отладку по USB → `adb install -r Builds\Android\Arena.apk`. Левый стик — движение (плавающий);
правый стик атаки — тап = автоприцел, потянуть и отпустить = ручной выстрел, вернуть в центр = отмена; стик ульты — так же; кнопка трюка.
Профилирование: `adb install -r Builds\Android\Arena-dev.apk` → Unity Profiler.

### Как запустить сервер и сыграть по LAN с телефона

1. **Сервер на ПК** (PowerShell в `C:\Dev\Arena`): `Tools\server-run.ps1`. .NET SDK не нужен — сервер собирается и запускается
   средствами Unity. В консоли — строка `listening on udp 0.0.0.0:7777`, раз в 10 с сводка. Метрики: http://127.0.0.1:7778/metrics.
   Остановка — Ctrl+C (идущие матчи доигрываются до 3 мин), второй Ctrl+C — сразу.
2. **Брандмауэр** (один раз, PowerShell **от администратора**; агент правила не меняет):
   `New-NetFirewallRule -DisplayName "Arena server" -Direction Inbound -Protocol UDP -LocalPort 7777 -Action Allow -Profile Private`.
   Wi-Fi на ПК должна быть «Частной сетью». Без правила Windows при первом запуске может сама спросить разрешение — ответить «Разрешить»
   для частных сетей.
3. **Телефон** в той же Wi-Fi: `adb install -r Builds\Android\Arena.apk` (старый APK этапа 2 с новым сервером не сыграет — другая
   версия протокола, покажет «Обновите игру»). В меню — «Играть 3 на 3» или «Последний зверь», регион «Локальная сеть» (сервер
   находится сам). Одному телефону через 5 с ожидания сервер добавит ботов; 2–6 телефонов попадут в один матч, если нажмут поиск
   в пределах 5 с.
4. Если «Локальная сеть» не находит сервер (гостевая сеть, «изоляция клиентов» на роутере): прописать IP ПК
   (`ipconfig` → IPv4) в регионах `DataSeeder` (`NetConfig.Regions`, D-101) и пересобрать APK (`Tools\build-android.ps1`) —
   агент может сделать это по вашей просьбе.
5. Пинг 150 мс в LAN для проверки ощущений: Development-сборка (`Tools\build-android.ps1 -Development`) + `NetConfig.DevSimEnabled`
   (задержка/джиттер/потери на клиенте) и dev-оверлей сети.
6. **Бесплатный VPS** (человек, без агента — регистрация и карта): ТЗ §10.3 — Oracle Cloud Always Free (ARM64, Ubuntu 24.04),
   открыть UDP 7777 в Security List и `ufw`, поставить .NET runtime ≥ 6, скопировать `Builds/Server/` (собирает
   `Tools\server-publish.ps1`), в `config/server.json` — `"LanDiscovery": false`, включить `deploy/arena-server.service`;
   метрики — только через `ssh -L 7778:127.0.0.1:7778`. Потом адрес VPS — в регионы `DataSeeder`, пересобрать APK.
   Docker (`Server/docker-compose.yml`) — по желанию, не проверялся (нет Docker и SDK).
7. Нагрузка заново: `Tools\server-load.ps1` (100 матчей, ≈ 2 мин); долгие тесты — `Tools\test.ps1 -Category Long` / `-Category Perf`.

### Что проверить руками (автоматика этого не видит, ТЗ §11.3)

1. ПК-сервер + 1 телефон: «Играть 3 на 3» → поиск → матч с ботами → итоги → «Ещё раз» → «Меню». То же в «Последнем звере»
   (туман, ягоды из ящиков, «Осталось N», место в итогах).
2. 2–6 телефонов в одном матче: нет рывков и «телепортов» чужих бойцов; свой боец отзывчив; попадания ощущаются честными
   (особенно ближний бой Бруно/Векса).
3. Вылет и возврат: авиарежим на 10 с посреди матча (бот играет за вас, потом управление возвращается); Wi-Fi ↔ LTE; свернуть
   приложение на 5–20 с; убить приложение и открыть — кнопка «Вернуться в бой».
4. Значок пинга в матче; экран «Связь потеряна — переподключаемся…».
5. Нагрев, батарея и трафик за матч на телефоне; LAN-обнаружение на вашем роутере.
6. Позже, с VPS: 6 игроков с пингом ≤ 150 мс — главный критерий этапа (GDD §3); мобильные сети, CGNAT, Wi-Fi с запретом UDP
