# A3.map — внедрение «Снежной долины» 3×3 для «Жёлудей» (D-144)

Источник: `Docs/Map-SnowValley.md` §6 (раскладка D-141). Коммит кода/ассетов — `78a751d`.

## Сделано
1. **Данные.** `DataSeeder`: `AcornsSnowValleyId = "acorns_snow_valley"`, `AcornsSnowValleyPath` (`Data/Maps/Acorns_SnowValley.asset`),
   массивы §1.2 дословно (сверено скриптом с `Tools/maps/snow_valley_acorns_half.txt`), `SeedAcornsSnowValley()` (3 спавна, симметрия,
   тема `Theme_Snow`). `DefaultMap = AcornsMaps[0] = SnowValley`, «Поляна» — `[1]`. Пакет контента переэкспортирован. Параметры режима не трогались.
   Декор: углы «П» у центра (8,10) (12,10) + зеркало — `L` (фонари, §1.4 В2а), остальное дословно.
2. **Вид.** `MapDecor.SmallGift = 'g'` (на `%`; вид — подарок темы по хэшу, поломка → кучка снега). `MapThemeConfig.Hollow` +
   `AcornsModeView.CreateHollow` (тема → меш с материалом реквизита темы; без темы — `HollowPrefab`). `SnowPropMeshes.BuildHollowSpruce`:
   ёлочка 3 яруса ≈ 1,6, в основании ≤ 1 клетки, снежный холмик с норками спереди/сзади, шары золото/жемчуг/абрикос/лиловый, 8 огоньков,
   звезда — 576 треуг. `SnowThemeBuilder` строит его и привязывает тему к обеим картам. `SnowTrailBuilder` — следы и от `A`/`B`.
   `MapView.CreatePropObject` стал public (нужен Modes). Ельник, стена с гирляндами, домики, сугробики, фонари — из D-142 без изменений.
3. **Тесты.** `SnowValleyAcornsMapTests` (4): 21×31, 3+3, дупло (10,15), симметрия, счёт клеток §1.3; BFS-связность, 0 «проходов 1»,
   `ScatterPoint` ×1000 — ни разу в блок-клетке; `$` не ломается (`BreakOverlapping` по кучке, `BoxSystem.ActiveCount == 0`), `%`+`g`
   ломается; декор валиден (8 `g`, 4 `L`), вид: 0 каменных блоков, все `#`/`%`/`$` с реквизитом, рамка, следы, кучка после поломки,
   ёлочка-дупло ≤ 1000 треуг. `SnowValleyAcornsBotMatchTests` — 10 сидов на «Долине» и для сравнения на «Поляне».
   Обновлены: `AcornsGladeMapTests` (`AcornsMaps[1]`), `ContentPackTests` (2 карты), `SnapshotMatchRig.Create(..., mapId)` +
   `SnapshotDeltaTests.SmallBudget...` на «Поляне» (на «Долине» боты за 30 с не встречаются — бюджет 160 Б не превышался).
4. **Скрины** `Tools/out/art/snow_3x3/`: `top.png` (сверху), `base.png` (камера команды 0 у спавна (10,2)), `centre.png` (у ёлочки).
   Запуск: `Tools/unity-method.ps1 -Graphics -Method Arena.Editor.Art.Capture.ArtCapture.CaptureAcornsMap`. Правка по скринам: не было следов
   (строились только от `S`) — добавлены от `A`/`B`; ёлочка сначала 2284 треуг. — урезана до 576.
