# A-TheoSfx — звуки Тео (2026-10-20)

Тео — мальчик ≈ 12 лет, космический рейнджер, «игрушечный» глянцевый 3D, огромный бластер (D-138). Нужны звуки,
сделанные **только своим синтезом** (Python + numpy/scipy → WAV 16-bit mono, 44.1 кГц или 22.05 кГц). Никаких сэмплов из
чужих игр, никаких скачиваний. Каждый файл → строка в `Docs/AssetLicenses.md` («оригинал, синтез скриптом, CC0/своё»).

## Что сделать (шаг 1 — только файлы, без Unity)
Скрипт `Tools/Audio/synth_theo.py` (детерминированный, фиксированный seed; параметры — вверху скрипта словарями) пишет в
`Assets/_Project/Audio/Fighters/Theo/`:
- `theo_step_01..04.wav` — шаги по арене: мягкие, короткие (60–120 мс), 4 варианта (лёгкий «топ» резиновой подошвы + чуть шороха).
- `theo_shot_01..03.wav` — выстрел бластера: энергетический, **тёплый** (не резкий лазер «пиу»): короткий низкий «тамп» +
  мягкая восходящая/нисходящая гармоническая волна + немного шума-«пшика», 150–300 мс, 3 вариации высоты.
- `theo_hit.wav` — попадание снаряда Тео во врага: плотный мягкий «шлёп» с искоркой, 100–180 мс.
- `theo_ult.wav` — ульта (залп/заряд): набор заряда 0.3 с + мощный разряд, 0.8–1.2 с.
- `theo_hurt_01..02.wav` — получение урона: глухой удар + короткий писк брони (без голоса), 120–200 мс.
- Голосовые «эмоции» без слов (синтез формантами/вокодер-подобно, детский тембр ~300–450 Гц, не страшно, не роботично
  слишком): `theo_vo_effort.wav` («хэ!» при ульте), `theo_vo_hurt.wav` («ай»/«ух»), `theo_vo_win.wav` (радостное «йе-е!»
  с восходящей интонацией), `theo_vo_lose.wav` (огорчённое «о-о…» нисходящее). 0.2–0.9 с.
- Нормализация: пик −1 dBFS, без клиппинга, фейды 3–5 мс (без щелчков), тишина в начале ≤ 5 мс.
- Превью для человека: `Tools/out/audio/theo_preview.wav` — все звуки подряд с паузами 0.4 с; плюс спектрограммы
  `Tools/out/audio/theo_sheet.png` (по одной мини-спектрограмме на файл, подписи).

## Не делать
- Не запускать Unity, не трогать C#, `.meta` не писать руками (Unity создаст при следующем импорте; коммитить WAV можно
  без .meta — следующий шаг Unity их сгенерит и закоммитит).
- Не трогать чужие незакоммиченные файлы (`Berry.mat`, `Fog.mat`, `ProjectSettings/*`, `Branding`, `FighterModel*`).
