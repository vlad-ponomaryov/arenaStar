## Что сделать каждому агенту (только Blender + Python, БЕЗ Unity)
1. Скрипт `Tools/Blender/fighters/build_<id>.py` (за основу — подход `build_theo_v3.py`: SDF/примитивы → единый меш,
   запечённая текстура 1024, кости `Root, Body, Head, ArmL, ArmR, LegL, LegR, Prop, EyeL, EyeR, LidL, LidR` (+ `Tail`/`Extra`,
   если нужно), оружие — отдельный FBX на `Prop` (`<id>_weapon.fbx`), хват как у Тео: оружие в руках, «вперёд» = направление
   взгляда). Стиль — «игрушечный» глянцевый 3D, крупная голова, читаемый силуэт сверху; пропорции как у Тео (рост 1.0 в
   Blender; Ковач/Брумм крупнее, Рен меньше — по описанию). Бюджет: тело ≤ 4000 треуг., оружие ≤ 1200.
2. Выход: `Art/Source/3D/<id>/` (`.blend` не обязателен; `<id>_game.fbx`, `<id>_weapon.fbx`, `<id>_tex.png`, `source.md` —
   параметры, кости, палитра, что не успел). Лист превью `Tools/out/art/roster3d/<id>_sheet.png` (спереди, 3/4, сзади,
   сверху, игровой ракурс сверху-сбоку) — тем же рендерером, что `render_theo_sheet.py` (скопируй/обобщи в
   `render_fighter_sheet.py` — **только если файла ещё нет**; иначе свой `render_<id>_sheet.py`, чтобы не конфликтовать).
3. Сам посмотри лист (Read PNG), до 2–3 итераций: силуэт и оружие узнаются, палитра из Roster-v4, ничего страшного (6+).
4. Коммит только своих файлов (`git add` по явным путям): `A.roster3d: <Name> base model (<tris> tris)` + последняя строка
   `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Если `index.lock` занят — подожди 10 с и повтори. Не пушить.

## Звуки (дополнение пользователя: «модели, звук, анимацию — всё»)
5. После модели — набор звуков героя своим синтезом: скрипт `Tools/Audio/synth_<id>.py` (за основу `synth_theo.py`,
   тот же формат/проверки), WAV в `Assets/_Project/Audio/Fighters/<Name>/` с теми же ролями файлов, что у Тео (`<id>_step_01..04`,
   `<id>_attack_01..03` — звук его оружия по описанию, `<id>_hit`, `<id>_ult`, `<id>_hurt_01..02`, `<id>_vo_effort/hurt/win/lose`;
   тембр голоса — по возрасту/полу героя, без слов). Строка в `Docs/AssetLicenses.md` (если файл занят другим — повтори
   правку после свежего чтения). Отдельный коммит `A.roster-sfx: <Name> synthesized sound set`.
- Анимация общая: процедурный `FighterAnimator` (A-TheoAnim) работает на любом FBX с костями выше — поэтому важны имена и
  пивоты костей (плечо, бедро, шея) и оружие на `Prop` с пустышкой `Muzzle` на конце (для стрелков) — опиши в `source.md`.
  Установку в Unity (рецепты, данные, звуки на события) потом сделает один агент по очереди — сам Unity не запускай.
