трогал сервер) → commit → строка в `Docs/NightLog.md`). PlayMode меняет `ProjectSettings/QualitySettings.asset` — не коммитить
(`git checkout` его). Unity — один процесс; параллельно работает другой агент, но только над документами. Коммить только свои файлы.
Можно несколькими коммитами (по пункту). Решения — в `Docs/Decisions.md` (новые D-номера после последнего).

## Пункты
1. **WASD в редакторе не работал.** Проверь `KeyboardMouseInput` / `LocalInputCollector` / настройки Input System
   (`activeInputHandler`, наличие `Keyboard.current`, фокус Game view, не перехватывают ли стики/UI ввод, не обнуляет ли стик WASD,
   работает ли в онлайн-матче). Почини причину, добавь тест, если возможно. В MorningReport кратко: «в редакторе кликнуть по окну Game».
2. **Выход из онлайн-матча, если сервер пропал** — `ConnectionOverlay`, п.1 Unity-ревью в `Docs/Stage3-TestAudit.md`. Кнопка «Меню»
   должна всегда работать (и во время переподключения), корректно закрывать сессию.
3. **Бот сложнее Easy.** Найди уровни сложности ботов (`BotBehaviourConfig`/DataSeeder, Arena.Bots). Добавь/включи уровень Normal
   (лучше прицел с упреждением, использование супера, уклонение, фокус на слабых) — параметрами в данных, без магических чисел.
   Выбор сложности — в меню тренировки, если там нет — по умолчанию Normal для офлайна и добора ботами онлайн. Тесты: Normal-бот
   выигрывает у Easy заметно чаще 50 % на серии детерминированных матчей.
4. **Короче ожидание перед добором ботами онлайн**: сейчас 15 с (параметр сервера) → 5 с по умолчанию (server.json/конфиг + Server-Spec).
