# A-Theo3D — 3D-модель Тео (стартовый стрелок)

Оркестратор — отдельная беседа (2026-10-19). Источник образа — D-137/D-138, `Docs/Roster-v4.md` §1.1.
Концепт (одобрен): `Art/Source/Flow/2026-10-19_theo_v8/theo_v8_1.png` — мальчик-блондин ≈ 12 лет, космический рейнджер,
красный #B3141C + золото #E0A93A + графит #3D3836, тёплое оранжевое свечение, огромный фантастический бластер, визор-монокль,
гарнитура, эмблема — золотая комета на оранжевом кольце орбиты, без плаща, без шлема. Оригинальность (CLAUDE.md §1): без
светильника-реактора в груди, без маски/лицевой пластины; чужие франшизы в промптах не называть.

Конвейер — как спайк Пикса (`Docs/Spike-ImageTo3D.md`, `Tools/Blender/prepare_fighter.py`, `Tools/Blender/fighters/pix.json`,
`Art/Source/3D/pix/source.md`): Flow-референс в A-позе на белом → RGBA-вырезка → TRELLIS.2 (официальное демо HF, вход
в аккаунт есть, 1 генерация/сутки; запасной — Space `Upsampler/trellis-2`) → Blender (нормализация, ремеш, цвет, бюджет,
кости FighterBone, автовеса) → FBX → Unity (ViewAssetBuilder/ViewCatalog, кодом).

## Шаг 2c — модель v3 (max), разбор, почему v1/v2 не вышли
- Обе — сборка из примитивов/SDF-деталей: читается как «конструктор», а не как цельная глянцевая фигурка 001. Золото —
  плоский жёлтый (нет металлического перелива/бликов), красный без градиента, всё одним тоном на деталь.
- Детали из 001 (гранёные наплечники, эмблема, канты, панельные линии, веснушки) не помещаются в вершинный цвет 4k.
- Пропорции: голова/плечи/кисти/ботинки не совпадают с 001 при наложении силуэтов; позы рук — «палки».
- Направления для v3: моделировать цельно (одна гладкая оболочка тела + накладные пластины с толщиной и фаской),
  проверять наложением силуэта на 001/002 по каждому виду (числовая метрика IoU силуэта), запекать детали из hi-poly
  в текстуру (цвет + AO + блик, 512–1024, ASTC) для игровой модели — если для этого нужна правка шейдера/импорта в Unity,
  описать её в source.md (шаг Unity сделает отдельный агент).
- 20.10 ≈ 07:47 UTC: TRELLIS.2 снова «daily ZeroGPU limit» — похоже, сутки скользящие от вчерашних ≈ 14:10–14:56 UTC;
  повтор после ≈ 15:00 UTC (18:00 МСК) 20.10.
