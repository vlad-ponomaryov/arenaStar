# «Снежная долина» LB — отзыв пользователя №1 (19.10, по скриншотам top/spawn)

Скрины: `Tools/out/art/snow_lb/top.png`, `spawn.png` (коммит 390f6fd, D-140).

## Слова пользователя (суть)
1. **Кусты похожи на траву со снегом — зимой травы нет.** Нужен другой зимний элемент, в котором по механике можно
   спрятаться (механика куста `"` остаётся, меняется вид).
2. **Деревья за краем карты выглядят ужасно — убрать.** Вместо них — забор: кладка из снежных кирпичей (как у
   крепостей), либо ледяная стенка, либо просто заборчик; на заборе — **гирлянды**.
3. **В целом смотрится пусто.**
4. **Лут (геймдизайн):** чем ближе к центру — тем больше скопления подарков, чтобы все бежали в центр:
   - у ёлки — кучки **по 3** подарка, плотно у ёлки (удобно ломать, выгодно бежать в центр);
   - чуть дальше от центра — кучки **по 2**;
   - у краёв, где спавны, — в основном **по одному**, в разных местах.

## Решения оркестратора (в D-номер при внедрении)
- Вместо «травы» — **молодой ельник**: плотная группа маленьких заснеженных ёлочек (конусы разной высоты, тёмная хвоя,
  снежные шапки), читается как «чаща ёлочек», не как трава. Контраст к снегу сохранить (D-136).
- Рамка — **стена из снежных кирпичей** (тот же стиль, что крепости, но неразрушаемый вид — на деревянном цоколе) с
  **гирляндой** из цветных огоньков (не цвета команд как доминанта; тёплые жёлтый/белый + немного цветных), столбики.
- «Пусто» — добавить оживляющий декор без влияния на бой: следы/тропинки на снегу, фонари у крепостей, гирлянда на ёлке
  крупнее, ёлка крупнее (сейчас приземистая), мелкие сугробики у стен; вне поля за забором — домики/дрова (концепт).
- Лут: переложить подарки кучками по правилу п.4; общее число — примерно прежнее (40–48), правило «свой подарок у спавна»
  сохранить; проверка `Tools/map_check.py`.
