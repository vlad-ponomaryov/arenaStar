# Лицензии ассетов

Правило (GDD §2, §11.2): каждый сторонний ассет, шрифт, звук, сервис — строка в таблице **до** коммита ассета.
Разрешены только лицензии, допускающие коммерческое использование. Ничего из Brawl Stars и других игр Supercell, даже как заглушки.
Платные ассеты не подключать без вопроса человеку.

## Сейчас

Сторонних ассетов нет. Временный арт — примитивы Unity (капсулы, кубы, сферы, цилиндры, плоскости), материалы и префабы
генерируются кодом (`Arena.Editor.Art.ViewAssetBuilder`). Звуки этапа 2 генерируются процедурно в коде (D-028).
