**Q-010 [открыт] (S2.11) — Детали Чомпа и Коры, которых нет в GDD (решено по D-060, просьба подтвердить после игры).**
(1) Аура «Травяной сбор» действует только на союзников, не на саму Кору. (2) «Купол» останавливает только вражеские снаряды снаружи;
навесные бомбы Чомпа, мины и рывки он не блокирует. (3) Купол лечит и саму Кору. (4) Мина взрывается в том же радиусе, в котором
срабатывает (1 клетка), без задержки взведения; установка мины раскрывает Чомпа в кусте на 1 с, как атака. (5) Отскок чашки выбирает
ближайшую цель, даже союзника с полным здоровьем.

**Q-011 [открыт] (S2.12) — Кора медленно убивает: среднее время убийства 8,7 с при цели GDD 3–4 с.** По числам GDD (600 урона,
заряд 1,5 с, 4200 HP) BalanceProbe даёт Кора→Бруно 13,9 с, Кора→Кора 9,4 с (таблица в D-061). Агент числа GDD не меняет; в тесте Кора —
исключение. Варианты: оставить (поддержка, сила — в лечении и отскоках), поднять урон чашки (например, 900) или ускорить заряд (1,1 с).
Также мелочи по D-061, решённые агентом: метка Новы ставится обеим пробитым целям; «Дымок» сразу снимает раскрытие от атаки; крюк в
купол врага ничего не делает; бонус «следующие 3 выстрела» считает очередь одним выстрелом. Подтвердите после игры.

**Q-012 [открыт] (S3 ТЗ, 2026-10-18) — Установить .NET 10 SDK?** На ПК нет .NET SDK (`dotnet` не найден). Серверу этапа 3 нужен
.NET 10 (LTS): `winget install Microsoft.DotNet.SDK.10` — это скачивание, поэтому его делает человек или разрешает агенту.
Пока: bootstrap-сборка Roslyn'ом и .NET 6.0.21 из Unity — проверено, Core+Bots собираются без правок (D-066). Подходит только
для разработки и LAN: .NET 6 снят с поддержки.
Рецензия (D-084): bootstrap перепроверен (UDP, JSON, SHA-256, HTTP-метрики работают), команда — в ТЗ §5.2; с `rollForward: Major`
та же сборка запускается и на VPS с любым .NET ≥ 6. **Этап не блокирует.** SDK даёт быстрый сокет .NET 8+ без выделений памяти,
Docker-образ и `dotnet publish`.
S3.4 (D-093): быстрый сокет `Server/Arena.Server/Host/UdpServerSocket.cs` (`#if NET8_0_OR_GREATER`) написан, но без SDK
не компилировался и не проверен — после установки SDK прогнать `Tools/server-test.ps1 -Mode Sdk` (self-test требует 0 Б аллокаций).

**Q-013 [открыт] (S3 ТЗ) — Транспорт: свой UDP или LiteNetLib (MIT)?** ТЗ выбирает свой транспорт (D-065, `Server-Spec.md` §3).
LiteNetLib зрелый и сэкономил бы около одного шага, но его нужно скачать с GitHub/NuGet — вне реестра Unity. По D-040
(«готовое вместо своего») он сильный кандидат. Разрешить скачивание как основной или как запасной вариант? Пока: свой транспорт
за интерфейсом, адаптер LiteNetLib возможен позже. **Этап не блокирует:** сторонние библиотеки скачиваются только с разрешения
(CLAUDE.md §4, D-040), поэтому основной путь — свой транспорт; рецензия упростила его (без фрагментации, D-082).

**Q-014 [открыт] (S3 ТЗ) — Где держать сервер?** Варианты: (1) ПК в LAN — бесплатно, сразу; нужно правило брандмауэра от администратора:
`New-NetFirewallRule -DisplayName "Arena server" -Direction Inbound -Protocol UDP -LocalPort 7777 -Action Allow -Profile Private`;
(2) бесплатный VPS — кандидат Oracle Cloud Always Free (ARM64; регистрация с картой — человек; проверить доступность для вашей
страны и карты); (3) дешёвый платный VPS — только с вашего разрешения. Какой регион ближе к тестерам? Пока: всё готовим под LAN,
инструкции — в ТЗ §10 (D-078). **Этап не блокирует:** путь «ПК + телефон в LAN» работает без хостинга. После выбора хостинга нужен
ещё канал оповещений о сбоях (GDD §8.3) — его тоже выбирает человек.

**Q-015 [закрыт — решение агента-рецензента, человек может пересмотреть] (S3 ТЗ) — Правила онлайн-матча, которых нет в GDD.**
Было решено по умолчанию (D-073, D-075): (1) ботов в матче не помечаем (GDD §13 — открытый вопрос); (2) одинаковых бойцов разводим
по разным командам, а если не получается — разрешаем; (3) вернуться в матч можно до его конца, хотя авто-попытки идут только 60 с;
(4) AFK 20 с — бойцом управляет бот, без выгона; (5) сложность ботов добора — «Лёгкий» до появления кубков (этап 4).
Решение (D-087): (1)–(3) — как было; (4) AFK — 30 с без касаний (20 с ловили бы тех, кто прячется в кусте); (5) добор — «Новичок»:
по GDD §7 он для первых 30 кубков, а кубков пока у всех 0. Всё меняется в `server.json` без новой сборки.

**Q-016 [закрыт — решение агента-рецензента, человек может пересмотреть] (S3 ТЗ) — Уровень защиты этапа 3.** Есть: защита от подмены
адреса, усиления и флуда, случайный `connectionId`, лимиты. Пакеты не шифруются и не подписываются секретным ключом — злоумышленник
в той же Wi-Fi теоретически может перехватить бойца в одном матче (D-074). Ключи сессии выдаст HTTPS-бэкенд на этапе 4.
Решение (D-088): откладываем до этапа 4 — аккаунтов и личных данных нет, ущерб ограничен одним матчем, флаг подписи в заголовке
уже зарезервирован.

**Q-018 [закрыт — решение агента-рецензента, проверить после игры] (S3 ТЗ) — Числа «Последнего зверя», которых нет в GDD (PROTO,
