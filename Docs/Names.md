# Варианты названия игры (рабочие)

Рабочее имя в коде — `Arena`. Финальное название выбрать и проверить по товарным знакам США/ЕС/РФ (ГДД, раздел 13). Без слов Supercell: Brawl, Clash, «…Stars».

Пожелание: чтобы звучало как Brawl Stars — два коротких ударных слога, жёсткие согласные (бр/кр/ст), похожие гласные, легко выкрикнуть.

- По звучанию: **Fang Gang**, **Snap Fang**, **Crash Paws**, Grit Pack, Brisk Tails, Rush Fur
- Тема звёзд/шоу: **Star Rumble**, Comet Crew, Galaxy Paws, Rumble Royale, Paw Arena
- Свои слова: **Zoomble**, **Furion**, Pawnix
- Ранние: Rumble Paws, Tail Storm, Acorn Wars, Wild Squad, Furball Frenzy, Beast Bash
