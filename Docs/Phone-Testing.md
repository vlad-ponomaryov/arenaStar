# Тестирование на телефоне

Телефон: Samsung Galaxy A36 (SM-A366E, Android 16), подключение по Wi-Fi без кабеля. Скрипт — `Tools/phone.ps1`,
adb берётся из Android SDK внутри Unity (`...\AndroidPlayer\SDK\platform-tools\adb.exe`), Unity для установки не нужен.
Пакет игры — `com.arena.prototype`.

## Каждый раз

```
powershell -ExecutionPolicy Bypass -File Tools\phone.ps1
```
Ставит самый свежий APK из `Builds/Android` (`Arena.apk` или `Arena-dev.apk` — что новее) и запускает игру.
Телефон должен быть разблокирован, в той же Wi-Fi сети, «Отладка по Wi-Fi» включена.
Если порт сменился (перезагрузка, отладку выключали), скрипт сам найдёт телефон в сети.

- `-Build` — сначала собрать свежий APK (`-Build -Dev` — development-сборку). Если Unity занят другим агентом,
  ставится последний готовый APK.
- `-Dev` — ставить `Arena-dev.apk`, даже если `Arena.apk` новее.
- `-Reinstall` — если установка падает с `INSTALL_FAILED_UPDATE_INCOMPATIBLE` (удалит игру вместе с данными).

## Если что-то не так — прислать лог

Сразу после проблемы (вылет, зависание, ошибка), не перезапуская игру:
```
powershell -ExecutionPolicy Bypass -File Tools\phone.ps1 -Log
```
Лог сохранится в `Tools/out/phone-log.txt` — скажите агенту «посмотри лог телефона». Перед каждым запуском игры
скриптом старый лог очищается, так что в файле только последняя сессия. `-Watch` — смотреть лог вживую (Ctrl+C).

## Настройка телефона (один раз, уже сделано)

1. Настройки → Безопасность и конфиденциальность → **Автоблокировщик** → выключить (иначе Samsung блокирует установку
   с компьютера).
2. Настройки → Сведения о телефоне → Сведения о ПО → 7 раз нажать **«Номер сборки»** → PIN.
3. Настройки → Параметры разработчика → **«Отладка по Wi-Fi»** → включить.
4. Нажать на «Отладка по Wi-Fi» → «Подключить устройство с помощью кода» и, не закрывая окно, выполнить:
   `Tools\phone.ps1 -Pair <IP:порт из окна> -Code <6 цифр>`. Адрес можно не читать с экрана: его показывает
   `adb mdns services` (строка `_adb-tls-pairing`).

Связка сохраняется: повторять шаг 4 нужно, только если телефон «забыл» компьютер (сброс, «Отозвать разрешения»).

## Запасные варианты

- **Кабель USB:** включить «Отладка по USB» в параметрах разработчика, подключить, на телефоне нажать «Разрешить»
  в окне «Разрешить отладку по USB?». Дальше тот же `Tools\phone.ps1` (USB выбирается первым).
- **Телефон без «Отладки по Wi-Fi» (Android 10 и старше):** один раз по кабелю `Tools\phone.ps1 -WifiFromUsb`, затем
  кабель можно отключить (до перезагрузки телефона).
- **Просто файлом:** перекинуть `Builds/Android/Arena.apk` на телефон (кабель как флешка, облако), открыть его
  в «Мои файлы» и разрешить установку из этого источника. Логов при этом не будет.
